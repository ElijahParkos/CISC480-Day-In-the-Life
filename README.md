# CISC480-Day-In-the-Life

## Day in the Life is a “choose-your-path” sustainability game for the University of St. Thomas, built as a CISC 480 capstone project in partnership with the UST Office of Sustainability.
Players move through a typical day as a Tommie, making everyday choices (how to get to class, what to eat, what to buy) and seeing how those choices impact the outward environment. This project builds on the existing Day in the Life game with the goal of making the learning content more specific, relatable, and better explained, so students leave with concrete reasons and habits they can actually apply.
## Team Members: Amber Kraft, Elijah Parkos, Kitty Marsh, Branden Shaffa.
### Problems to solve:
1.	Improve explanations and learning content: the current game tells you what happens after a choice, but not detailing why it's the sustainable one.
2.	Points imply some sustainable actions are "worth more" than others, which isn't the message we want to send
People act sustainably when they have a concrete mental process (knowing how and where to recycle, compost, etc.), not just awareness that it's good to do.
### Objectives:
1.	Add more branching story paths (the current game seems to be one path with multiple options per step)
2.	Reference and compare each answer option in its explanation.
3.	Include at least as many fun facts as the original.
4.	Add an ending summary that varies by the path taken.
Target users: UST students (primary), faculty for classroom use (secondary).
### In scope
•	Engaging storylines with multiple, realistic, meaningful choices
•	UST-specific scenarios referencing real campus buildings and locations
•	Revealing the consequences of unsustainable choices
•	Different pathways through the day
•	An improved scoring / feedback system
### Out of scope (future releases)
•	Visuals for scenarios / campus map
•	Saving student responses for analysis
•	Dynamic point system rewarding consistency
•	Randomized paths
•	Reflection questions
•	Personalized stories from a student survey
### Tech Stack:
•	Vanilla JavaScript + HTML/CSS 
•	GitHub 
•	Data sources: Office of Sustainability materials, AASHE STARS data, and cited fun-fact sources.
### Timeline:
Two-week sprints with four demos.
Demo 1: First-draft scoring system, bulk storyline/path concepts, basic code architecture, semi-playable.
Demo 2: Detailed storylines, visual/UX design drafts, iterative code improvement (MVP).
Demo 3: Final scoring system, visuals implemented, fine-tuned stories, everything working.
Demo 4: Play testing with students, feedback applied, finishing touches, coordination with the gallery team.
